# Learning Java Projects

This repository is a small Java learning workspace used to practice core Java concepts, basic project setup, and simple console-based applications.

## Projects included

### 1. 21DayaChallenge
A Java practice project focused on problem solving and algorithm implementation.

- File: `21DayaChallenge/src/day1/FibonacciSerise.java`
- Purpose: prints Fibonacci numbers up to a user-provided limit
- Includes examples of:
  - recursive logic
  - iterative logic
  - performance-oriented approach using caching

### 2. StandaloneProj_One_One
A standalone Java project used for beginner exercises and Git practice.

- `src/com/dev/HelloWorld.java` prints a simple greeting
- `src/com/kichu/GitTesting.java` demonstrates a basic Java class and console output

## Technologies

- Java
- Eclipse project files (`.classpath`, `.project`)
- Git/GitHub for version control practice

## Learning goals

- understand Java project structure
- write and run console-based Java programs
- practice basic Java logic and algorithms
- learn Git and repository management

## Running the projects

Open the project in an IDE such as Eclipse or IntelliJ IDEA and run the `main` methods in the Java classes.

Example:

- `day1.FibonacciSerise` for Fibonacci printing
- `com.dev.HelloWorld` for a sample Java application
- `com.kichu.GitTesting` for a second beginner program

This repository is intended to document ongoing learning and Java practice exercises.
